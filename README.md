# 采办 · 采购工作台在线试用

免费项目演示，支持案件、每日跟进、中英文草稿、附件、Excel/CSV 导入及周报。

## 报价比价

打开网站左侧「报价比价」，选择内置版式。填写内部料号、品名、采购数量和单位，再将各家 PDF 拖入对应栏位。多项报价由采购确认合并或分开，Excel 总价按所填采购数量计算。

有美金报价时，选择带换算栏的版式，填写一次当月汇率。Excel 以 US 和 MY 显示原价与换算单价。核对后可导出原格式 Excel。

公开站点包含构建后的网页、开源软件版权说明、虚构演示案例和空白比价版式。报价、模板和手册在访客浏览器内处理，试用数据保存在当前浏览器。支持文字型 PDF，扫描件可手动输入明细。

GitHub Pages 从 main 分支根目录发布。

## 案件流程

「全部案件」显示当前阶段及下一步。点开案件可查看九个阶段、记录 PO 邮件发送和回签、跟进 TT 付款及到期日。eFlow 签核与汇款在相应系统办理，工作台记录进度。
