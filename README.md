# 采办 · 采购工作台在线试用

免费项目演示，支持案件、每日跟进、中英文草稿、附件、Excel/CSV导入及周报。

## 报价比价

打开网站左侧“报价比价”。第一次选择自己的原 XLSX 模板，填写内部料号、品名、采购数量及单位，再将 PDF 拖入各供应商栏位。原报价数量只供核对，不覆盖采购数量。

一份报价有多项时必须选择“合并成一项”或“分开比价”，并确认明细对应。核对单价、币别、数量口径后导出。导出以原 XLSX 为基础，保留原有格式。
